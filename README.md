# AISecure Conf 2027 - International Conference on AI Security

## Conference Details
- **Title:** AISecure Conf 2027: International Conference on AI Security
- **Theme:** Defending Autonomous Intelligence, Foundation Models & Critical Infrastructure
- **Dates:** May 15–17, 2027
- **Venue:** University of Constantine 2 - NTIC Auditorium, Constantine, Algeria
- **Capacity:** 150 participants
- **Design Direction:** Terminal / Code (Dark theme with Emerald/Amber accent)

## Team Notes 
- **Pages Overview:** Home, Program, Speakers, Venue, FAQ, Gallery, Contact, Register, and Organizer Area.
- **Visitor Actions:** Browse conference info, countdown, program, speakers, venue, FAQ, and gallery; send contact messages; register (with student certificate upload when applicable).
- **Stored Data (Database):** Conference info, organizers, speakers, sessions, registrations (and selected sessions), and contact messages.
